# Contributing

1. Read `.cursor/rules/agent.mdc`. It sets the audience, what never goes on the site, and where the facts come from.
2. Check every claim against the product repository before writing it.
3. Add new pages to `docs.json`.
4. Run `npx mint dev` to preview and `npx mint broken-links` to check links.
5. Push to `main`. Mintlify deploys on every push.
