If you have customers or prospects in a spreadsheet or another CRM, you can bring them into Alva with the CSV import wizard.

## Starting an import

Go to **Companies** and click **Import**. The wizard imports companies. Files can be up to **25 MB** and **10,000 rows**.

## The import wizard

The wizard has five steps: **Upload**, **Preview**, **Map Fields**, **Configure**, and **Results**.

<Steps>
  <Step title="Upload">
    Drag and drop a CSV file, or click to choose one.
  </Step>
  <Step title="Preview">
    Check the first rows of your file to make sure it has been read correctly.
  </Step>
  <Step title="Map Fields">
    Match your CSV columns to Alva's company fields. Alva suggests mappings from your column names — confirm or change them. If you've saved a template, choose it from **Load template...** to apply its mappings.
  </Step>
  <Step title="Configure">
    Choose how to handle duplicates and which tags to apply, then review the **Import Summary** and start the import.
  </Step>
  <Step title="Results">
    See how many companies were **Created**, **Updated**, **Skipped**, and **Failed**, with the reason for each failed row.
  </Step>
</Steps>

### Fields you can map

| Alva field | Notes |
|---|---|
| **Company Name** | Required |
| **Domain** and **Website** | Used to spot companies you already have |
| **Industry**, **Company Size**, **Location**, **Description** | |
| **Relationship Type** | Customer, vendor, partner, supplier, or competitor |
| **Lifecycle Stage** | For example, target, prospect, lead, or customer. See [Companies and contacts](/crm/companies-and-contacts#lifecycle-stages) |
| **Primary Email**, **Primary Phone**, **LinkedIn URL** | |

For example:

| Your CSV column | Maps to |
|----------------|---------|
| "Company Name" | Company Name |
| "Website" | Website |
| "Sector" | Industry |
| "City" | Location |
| "Type" | Relationship Type |

### Duplicate handling

Alva treats a row as a duplicate when it matches a company you already have, by domain first and then by name.

| Option | What it does |
|--------|-------------|
| **Skip duplicates** | Existing companies are left as they are |
| **Update duplicates** | Existing companies are updated with the data from your file |
| **Create new records** | A new company is always created, even if it's a duplicate |

### Tags

Optionally choose [tags](/crm/tags) to apply to every company in the import — useful for marking where a list came from, such as "Trade Show 2026" or "Old CRM export".

## Import templates

If you import the same kind of file regularly, click **Save as Template** on the summary to save your field mappings and settings under a name. Next time, choose the template from **Load template...** on the **Map Fields** step.

## Importing with Alva

You don't have to use the wizard:

- **In chat** — paste CSV data into the Alva panel and ask her to import it. This suits small lists. For bigger files, she'll point you to the wizard.
- **By email** — attach a CSV to an email to your account's Alva address. Alva describes what's in the file first, and imports it only after you say yes. See [Alva by Email](/ai-assistant/alva-by-email).

Alva can set each company's relationship type from a column in the file, or apply one to every row, and tag everything she imports.

## Do-not-contact lists

A list of people or domains you must never email doesn't belong in a company import. Add it to **Settings → Email Block List** instead, so no email goes to them. See [Email block list](/email/email-block-list).

<Tip>
  Clean your CSV before you import it: remove blank rows, keep formatting consistent, and include a domain or website column for each company. Domains are the most reliable way to spot duplicates, and they stop existing customers from later showing up as new prospects in Discovery.
</Tip>
