Tags let you label and group companies — by source, priority, campaign, or anything else that helps you organise your pipeline. Tags apply to companies only.

## Creating and managing tags

Go to **Settings → Tags** and click **Create Tag**. Each tag has:

- **Name** — a short label, such as "Enterprise", "Inbound lead", or "Trade Show 2026"
- **Colour** — so you can spot it at a glance
- **Description** — optional

From the same page you can edit or delete any tag.

## Applying tags

You can tag companies:

- **On the company's page** — add or remove tags in the header
- **In bulk on the Discovery Pipeline** — select companies and use **Add Tags** to tag them all at once. See [Discovery companies](/discovery/discovery-companies)
- **During a CSV import** — choose tags to apply to every company in the file. See [Importing data](/crm/importing-data)

A company can have as many tags as you like.

## Using tags

The Companies list doesn't filter by tag. Tags are useful elsewhere:

- **Calling sessions** (Pro) — choose tags when you start a session to build the call list from tagged companies. See [Calling sessions](/calling/calling-sessions)
- **Alva** — ask it to list, count, or work with the companies that carry a tag

## Managing tags with Alva

Alva can do all of this for you. For example:

- "What tags do we have?"
- "Create a tag called Q1 Priority in red"
- "Rename the Webinar tag to Webinar 2026"
- "Tag Acme, Globex, and Initech as Enterprise"
- "Delete the Old List tag"

<Tip>
  Set up your tags before you start importing and adding companies. It's much easier to apply them consistently from the start than to go back and tag everything later.
</Tip>
